1Terminal y archivos

  1. Muestra la ruta de la carpeta donde estás parado.

    pwd

  2. Dice con qué usuario tienes la sesión abierta.

    whoami

  3. Lista lo que hay en la carpeta actual.

    ls

  4. Lista todo, incluidos ocultos, con permisos, dueño y tamaño legible.

    ls -lah docs

  5. Cambia de carpeta. Con .. sube un nivel y con ~ vuelve a tu home.

    cd ~/laboratorio-cli

  6. Dibuja una carpeta y todo lo que tiene adentro en forma de árbol.

    tree ~/laboratorio-cli

  7. Crea carpetas, incluidas las intermedias que falten. Con llaves crea varias de un jalón.

    mkdir -p ~/laboratorio-cli/{docs,src,logs}

  8. Crea archivos vacíos (o actualiza su fecha si ya existen).

    touch docs/{guia,notas}.md src/{main,test}.py README.txt

  9. Copia archivos. Con -r copia carpetas completas.

    cp -r docs docs_respaldo

  10. Mueve o renombra archivos y carpetas.

    mv notas.md apuntes.md

  11. Borra archivos. Con -r borra carpetas; no hay papelera, así que cuidado.

    rm -r docs_respaldo

  12. Borra una carpeta solo si está vacía.

    rmdir carpeta_vacia

  13. Crea un acceso directo (enlace simbólico) a otro archivo o carpeta.

    ln -s ~/laboratorio-cli/logs ~/logs

  14. Dice qué tipo de archivo es, sin importar su extensión.

    file README.txt

  15. Muestra todos los datos de un archivo: tamaño, permisos y fechas.

    stat README.txt

  16. Escribe texto con saltos de línea y lo manda a un archivo, sobrescribiéndolo.

    printf 'error\nok\nerror\n' > logs/app.log

  17. Agrega texto al final de un archivo sin borrar lo que ya tenía.

    echo 'ok' >> logs/app.log

  18. Manda los mensajes de error a un archivo aparte.

    ls carpeta_que_no_existe 2> errores.txt

  19. Pasa la salida de un comando como entrada del siguiente.

    cat logs/app.log | grep error

  20. && corre el segundo comando si el primero salió bien; || solo si falló.

    mkdir pruebas && cd pruebas

  21. Editor de texto dentro de la terminal. Ctrl+O guarda, Ctrl+X sale.

    nano logs/app.log

  22. Imprime el contenido de un archivo en la terminal.

    cat logs/app.log

  23. Abre un archivo largo para leerlo por partes. q sale, / busca.

    less /var/log/syslog

  24. Muestran las primeras o las últimas líneas de un archivo.

    tail -n 20 logs/app.log

  25. Sigue un archivo en vivo y muestra las líneas nuevas conforme llegan.

    sudo tail -f /var/log/nginx/access.log

  26. Cuenta líneas, palabras y caracteres.

    wc -l logs/app.log

  27. Busca texto dentro de archivos. -i ignora mayúsculas, -r busca en carpetas, -n da el número de línea.

    grep -n error logs/app.log

  28. Ordenan líneas y quitan las repetidas. uniq -c además las cuenta.

    sort logs/app.log | uniq -c

  29. Saca una columna de cada línea usando un separador.

    cut -d: -f1 /etc/passwd

  30. Compara dos archivos y muestra en qué líneas son distintos.

    diff guia.md notas.md

  31. Busca archivos por nombre, tipo, tamaño o fecha.

    find ~ -name '*.sh'

  32. Cambia permisos. 7 = rwx, 6 = rw-, 5 = r-x, 4 = r--; en orden dueño, grupo, otros.

    chmod 775 logs && chmod 664 README.txt

  33. Cambia permisos con letras: u dueño, g grupo, o otros; + da y - quita.

    chmod g-w README.txt

  34. Cambia el dueño (y el grupo) de un archivo.

    sudo chown spartabaldo:spartabaldo README.txt

  35. Muestra qué permisos se le quitan por defecto a los archivos nuevos.

    umask

  36. Abre el manual de cualquier comando. q para salir.

    man ls

  37. Muestra una ayuda corta del comando, más rápida que man.

    ls --help

  38. Lista los comandos que has escrito. !número repite uno.

    history | tail

  39. Limpia la pantalla de la terminal (o Ctrl+L).

    clear

2Scripts en bash

  1. Primera línea del script: le dice al sistema qué intérprete lo ejecuta.

    #!/bin/bash

  2. Le da permiso de ejecución al script y luego lo corre desde la carpeta actual.

    chmod +x saludo.sh && ./saludo.sh

  3. Corre un script sin darle permiso de ejecución.

    bash saludo.sh

  4. -n revisa la sintaxis sin ejecutar; -x muestra cada línea conforme corre.

    bash -x saludo.sh

  5. Imprime texto o el valor de una variable.

    echo "Hola $nombre! Bienvenido a Linux!"

  6. Guarda un valor. Sin espacios alrededor del =, y se lee con $.

    nombre="Jonathan"; echo $nombre

  7. Guarda en una variable lo que imprime un comando.

    hoy=$(date +%d/%m/%Y)

  8. Pide un dato al usuario mostrando un mensaje y lo guarda en una variable.

    read -p "¿Cuál es tu nombre? " nombre

  9. Usa el valor de la variable o, si viene vacía, un valor por defecto.

    base=${base:-0}

  10. Hace operaciones aritméticas con enteros.

    area=$((base*altura))

  11. $0 es el nombre del script, $1 el primer argumento y $# cuántos argumentos llegaron.

    ./listado.sh /home/spartabaldo/weas/Scripts

  12. Guarda cómo terminó el último comando: 0 es que salió bien.

    ls /noexiste; echo $?

  13. Termina el script y devuelve un código; 0 es éxito.

    exit 1

  14. Agrupa instrucciones con un nombre para reutilizarlas. local hace que una variable solo exista adentro.

    mostrar_ayuda(){ echo "Uso: $0 <directorio_origen>"; }

  15. Repite instrucciones por cada elemento de una lista, por ejemplo cada archivo de una carpeta.

    for archivo in "$origen"/*; do echo "$archivo"; done

  16. Repite contando de un número a otro.

    for i in {1..5}; do echo "Vuelta $i"; done

  17. Repite mientras se cumpla una condición; lo usamos para el menú de respaldo.

    while true; do read -p 'Opción [1-3]: ' op; done

  18. Sale de un ciclo antes de que termine.

    [ "$op" = 3 ] && break

  19. Revisa una condición. -f pregunta si la ruta es un archivo normal.

    if [ -f "$archivo" ]; then echo sí; fi

  20. -d pregunta si es carpeta; -e, si existe cualquier cosa con ese nombre.

    [ -d logs ] || mkdir logs

  21. Comparan números: igual, menor que, mayor que.

    if [ "$edad" -ge 18 ]; then echo mayor; fi

  22. Comparan texto: = si son iguales, -z si viene vacío.

    if [ -z "$nombre" ]; then echo 'Falta el nombre'; fi

  23. Elige qué hacer según un valor, como la extensión de un archivo o la opción de un menú.

    case "${archivo##*.}" in txt|md) echo texto ;; *) echo otro ;; esac

  24. Corta todo lo que hay antes del último punto; sirve para sacar la extensión.

    echo "${archivo##*.}"

  25. basename deja solo el nombre del archivo; dirname deja solo la carpeta.

    basename /home/spartabaldo/weas/notas.md

  26. Guardan varios valores en una sola variable.

    frutas=(uva pera); echo "${frutas[0]}"

  27. Hace que una variable la vean también los programas que abras desde ahí.

    export EDITOR=nano

  28. Crea un atajo para un comando largo. Se guarda en ~/.zshrc o ~/.bashrc.

    alias ll='ls -lah'

  29. Vuelve a leer un archivo de configuración sin cerrar la terminal.

    source ~/.zshrc

  30. Muestra la fecha y la hora, con el formato que le pidas.

    date '+%d/%m/%Y %H:%M'

  31. Hace una pausa de los segundos que le digas.

    sleep 2

  32. Programa un script para que corra solo cada cierto tiempo.

    0 8 * * * /home/spartabaldo/weas/Scripts/respaldo.sh

3Sistema, usuarios y paquetes

  1. Corre un comando con permisos de administrador.

    sudo apt update

  2. Cambia a otro usuario; sin nombre cambia a root.

    su - spartabaldo

  3. Actualiza la lista de paquetes e instala programas.

    sudo apt install -y lynis

  4. Actualiza los programas que ya tienes instalados.

    sudo apt upgrade -y

  5. Desinstala un programa.

    sudo apt remove cowsay

  6. Busca paquetes por nombre o muestra la información de uno.

    apt show nginx

  7. Intenta reparar dependencias rotas antes de instalar algo más.

    sudo apt --fix-broken install

  8. Lista los paquetes instalados.

    dpkg -l | grep bind9

  9. Convierte la llave de un repositorio al formato que usa apt.

    curl -fsSL URL | sudo gpg --dearmor -o /usr/share/keyrings/cisofy.gpg

  10. Escribe en un archivo (aunque sea de root) y muestra lo mismo en pantalla.

    echo 'deb ...' | sudo tee /etc/apt/sources.list.d/cisofy-lynis.list

  11. Audita la seguridad del sistema y guarda el reporte en /var/log.

    sudo lynis audit system

  12. Muestran tu usuario, tu número de usuario y a qué grupos perteneces.

  13. Crean un usuario nuevo; adduser pregunta los datos paso a paso.

  14. Cambia la contraseña de un usuario.

  15. Agrega un usuario a un grupo sin sacarlo de los demás.

  16. Borra un usuario junto con su carpeta personal.

  17. Lista todos los procesos que están corriendo.

  18. Muestran en vivo qué procesos usan más CPU y memoria. q para salir.

  19. Detiene un proceso usando su número (PID). -9 lo fuerza.

  20. Detiene procesos usando su nombre.

  21. & manda un comando al fondo; jobs lista, fg lo trae al frente y bg lo sigue en el fondo.

  22. Muestra cuánto espacio libre queda en cada disco.

    df -h

  23. Dice cuánto pesa una carpeta.

    du -sh ~/weas

  24. Muestra cuánta memoria RAM se está usando.

  25. Muestra la versión del kernel y el tipo de sistema.

  26. Cuánto tiempo lleva prendida la máquina y qué tan cargada está.

  27. Lista los discos y sus particiones.

    lsblk

  28. Dice en qué carpeta está el programa que se ejecuta con ese nombre.

  29. Muestra los registros (logs) del sistema y de cada servicio.

  30. Junta carpetas en un solo archivo y lo comprime (c crea, x extrae, z comprime).

  31. Comprimen y descomprimen archivos .zip.

  32. Calcula la huella de un archivo para revisar que no cambió.

  34. Reinician o apagan la máquina.

4DNS, web y SSH

  1. Muestra el nombre de la máquina; con -I, sus IPs.

    hostname -I

  2. Muestra cada tarjeta de red con su IP en una línea.

    ip -br -4 address

  3. Muestra la ruta por defecto, o sea el gateway de la red.

    ip -4 route show default

  4. Configura la red de NetworkManager; aquí se usa para dejar la IP fija.

    nmcli connection show

  5. Comprueba si otra máquina responde por la red.

    ping -c 4 10.10.24.199

  6. Muestra por qué equipos pasa un paquete hasta llegar a su destino.

    traceroute 10.10.24.1

  7. Lista los puertos abiertos: 53 es el DNS, 80 la web y 22 SSH.

    ss -lnut

  8. Archivo donde se le dice a la máquina a qué IP va un nombre, sin preguntar al DNS.

    cat /etc/hosts

  9. Archivo que dice a qué servidor DNS le pregunta la máquina.

    cat /etc/resolv.conf

  10. Arranca, reinicia, habilita o revisa servicios como named, nginx y ssh.

    sudo systemctl enable --now ssh

  11. Muestra si un servicio está corriendo y sus últimos mensajes.

    systemctl status named

  12. Revisa que la configuración de BIND9 no tenga errores.

    sudo named-checkconf -z

  13. Revisa que el archivo de zona del dominio esté bien escrito.

    sudo named-checkzone spartabaldo.linux /etc/bind/db.spartabaldo.linux

  14. Pregunta a un servidor DNS a qué IP apunta un nombre.

    dig @10.10.24.199 spartabaldo.linux +short

  15. Consulta inversa: a qué nombre pertenece una IP.

    dig @10.10.24.199 -x 10.10.24.199 +short

  16. Hace lo mismo que dig con una salida más sencilla; sirve en Windows.

    nslookup spartabaldo.linux 10.10.24.199

  17. Otra forma rápida de preguntar la IP de un nombre.

    host spartabaldo.linux 10.10.24.199

  18. Revisa que la configuración de nginx esté bien antes de recargarla.

    sudo nginx -t && sudo systemctl reload nginx

  19. Crea un enlace; así se activa un sitio de nginx.

    sudo ln -s /etc/nginx/sites-available/spartabaldo.linux /etc/nginx/sites-enabled/

  20. Pide una página web desde la terminal. -I muestra solo los encabezados.

    curl -I http://spartabaldo.linux

  21. Descarga un archivo de una URL.

    wget http://spartabaldo.linux/comandos.txt

  22. Abre una sesión en otra máquina o le manda un solo comando y regresa.

    ssh spartabaldo@10.10.24.199 "ls -lah /var/www/spartabaldo.linux"

  23. Crea un par de llaves para entrar por SSH sin escribir la contraseña.

    ssh-keygen -t ed25519

  24. Copia tu llave pública al servidor para que te reconozca.

    ssh-copy-id spartabaldo@10.10.24.199

  25. Copia archivos entre máquinas usando SSH.

    scp spartabaldo@10.10.24.199:/var/www/spartabaldo.linux/comandos.txt .

  26. Copia o sincroniza carpetas entre máquinas; solo manda lo que cambió.

    rsync -av ~/weas/ spartabaldo@10.10.24.199:/home/spartabaldo/respaldo/
